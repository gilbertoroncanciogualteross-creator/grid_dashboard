# Grid Dashboard

## What it does

A Dashboard shell with a header, sidebar, and a card area, plus a light/dark theme toggle.
https://grid-dashboardd.netlify.app/

## What I learned

- `fr` is a unit that only exists in Grid.
- Grid organizes elements in two dimensions: rows and columns.
- A theme toggle can be done with a script, and in the CSS the colors
  defined in `:root` get inverted.

## Running it locally

```bash
git clone https://github.com/gilbertoroncanciogualteross-creator/grid-dashboard.git
cd grid-dashboard
```
